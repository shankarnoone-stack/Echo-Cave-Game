# Echo-Cave-Game
A game based on how echolocation bounces back through the walls of the maze. Your main objective is to find the gold to win, but be careful of the hunter that tries to seek you. Also there are a certain amount of crystals to be found in each level that can be used to buy stuff from the shop (coming soon).

![Echo Cave main game](Screenshot%202026-11-14%20174506.png)

# HOW TO PLAY
The game was created using JavaScript, and you can use the code however you would like to. When you load into the game press the start button to load into the level. You can move by using either WASD or the arrow keys (W or up arrow to move forwards, down arrow or S to move backwards, left arrow or D to move left, and lastly press A or the right arrow key to move right). Also using the E key deploys fake pings, and the ESC key can be used to either restart or pause the game. When the hunter comes near you your screen starts to flash/become red to alert the player. 

# INSTALLATION 
The code is compressed into one file (CSS and HTML), so download the file, then extract (unzip) the file after that you should see two files and then go into an engine that supports javascript and html (we used CodeHS) and paste both the files' content into two seperate files (style.css and index.html), and then the game should load.
